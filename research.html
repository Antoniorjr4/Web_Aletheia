See Documentation → Rev11 research preview. Zero successes here does not imply zero risk. CIs are Wilson intervals. Remaining tasks, suites and stronger attacks need evaluation.

The axiom audit

Reported audited dependencies: propext, Quot.sound and Classical.choice. Formal claims are tested with lake build --wfail.

What is not yet proved

A complete Rust/Lean refinement is not established. The linear capability model of Lean differs from reusable tool capabilities in the ARX runtime. The v0.9 core includes typed await and atomic; T6 still has specified saga-body restrictions and resting-contract assumptions. Complete implementation refinement is unproved.

From proof to executable

The draft RC1 runs a complete examples/rc1/treasury.ath program against a persistent SQLite-backed service. athc recover restarts recovery in a new process after a real SIGKILL. Providers are declared idempotent, queryable or opaque.

Limits of the candidate

The PR #5 is unmerged. Provider behavior, fsync durability, authenticity of confirmation files and one-writer-per-WAL are assumptions. Recovery closes outstanding obligations; it does not resume the interrupted program. The Python runtime does not yet have the real RemoteHost adapter.
